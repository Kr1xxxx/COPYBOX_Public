三个部分

话术

客服常用回复按目录放好。搜索能用拼音和首字母。带【变量】的话术，复制前先把空填上。常用的排在最前面。

账号

登录、支付、接口密钥、验证码分开存。可以设一个密码，设了以后这部分会单独加密，还会给你一个恢复码。

图片

常发的图片存进来，点一下就复制。有目录、九宫格和回收站。

用起来顺手

  • 托盘小窗点托盘图标弹出小窗口，复制完自动收起。
  • 搜索几个词可以一起搜，只搜当前目录或者全部都行。
  • 备份备份文件是加密的，密码自己设；每天自动备份一次。
  • AI 润色和整理可选功能，填上自己的接口就能用。
  • 公司共享话术管理员给一个文件，自动同步，不会覆盖你自己的话术。
  • 主题跟随系统、浅色、深色，三种随你选。

安装与更新

  1. 下载安装包。
  2. 双击运行。
  3. 看到「未知发布者」，就点「更多信息」，再点「仍要运行」。
  4. 用过旧版的话：先在旧版里点「设置 → 数据 → 导出到新版」，再在新版里点「从旧版导入」。

更新时回到这里下载新版本，直接覆盖安装，数据不会丢。
