使用说明

Copyboxx 分话术、账号、图片三个部分，下面每样说个大概。找不到的可以先看常见问题。

话术

话术就是客服常用的回复，按目录放好，点一下就复制。搜索能用拼音和首字母，比如搜「tk」能找到「退款」。带【变量】的话术先填空再复制，常用的可以收藏，排在最前面。

账号

登录账号、付款方式、验证码这些资料分类存在这里，点一下复制。可以设一个密码，设了以后这部分单独加密。设密码时给你的恢复码一定要存好，密码和恢复码都丢了，谁都打不开。

图片

尺码表、产品图、收款码这些常发的图片存在这里，点一下就复制。可以选文件、拖进来或者直接粘贴，也能分目录。删掉的图片先进回收站，还能恢复。

托盘小窗

Copyboxx 开着的时候，屏幕右下角的托盘里有它的图标，点一下会弹出一个固定在最上面的小窗口，适合边聊边复制。复制完要不要收起、点关闭按钮时是收到托盘还是退出，都可以自己选。

备份与恢复

「设置 → 数据 → 完整备份」会把话术、账号、图片和设置打包成一个文件，用你自己设的密码加密，这个密码找不回，请记好。软件默认每天自动备份一份，保留最近 7 份。

公司共享话术

公司统一维护的话术，可以同步到每个人的 Copyboxx 里。在设置首页的「账号与同步」填上公司给的企业同步码就行，你自己写的和改过的话术不会被覆盖。没有同步码时，也可以在「设置 → 数据 → 共享话术」用公司发来的文件同步。

AI 润色和整理

这是可选功能，不用也不影响别的。在「设置 → AI」里选一个服务、填上你的密钥，话术旁边就能用「AI 润色」和「AI 整理」。密钥加密保存在本机，备份里不带。

设置

主题可以选跟随系统、浅色或深色。在「设置 → 数据」里点「打开文件夹」能看到数据放在哪，请不要把整个文件夹拷给别人。回收站可以设过多少天自动清理。

常见问题

数据存在哪里？

都在你自己的电脑上，加密保存，不会上传。在「设置 → 数据 → 数据位置」能打开它所在的文件夹。

忘了账号密码怎么办？

用设密码时给你的恢复码找回，再设一个新密码。密码和恢复码都丢了，账号里的内容就打不开了，所以恢复码一定要存好。

换电脑怎么搬？

在旧电脑点「设置 → 数据 → 完整备份」，设一个密码，把文件拷到新电脑。新电脑装好以后点「从完整备份恢复」，输入同一个密码。

AI 的密钥不在备份里，到新电脑上要重新填一次。

为什么 Windows 提示未知发布者？

安装包没有做数字签名，所以 Windows 会提醒一下。点「更多信息」，再点「仍要运行」就能装。

和旧版 Clipbox 是什么关系？

Copyboxx 就是原来的 Clipbox（之前也叫过 Clipboxx），只是改了名字。旧版的数据可以搬过来：先在旧版点「设置 → 数据 → 导出到新版」，再在新版点「设置 → 数据 → 从完整备份恢复」。详细步骤见从旧版搬数据。
