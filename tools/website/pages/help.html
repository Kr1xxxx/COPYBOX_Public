使用说明

Clipboxx 分话术、账号、图片三个部分。下面按部分说怎么用，找不到的可以先看常见问题。

话术

话术就是客服常用的回复。点一下就复制，到聊天窗口里粘贴就行。

目录

左边是目录，可以新建、改名、换颜色、拖动排序。自带的话术目录不能删，只能改颜色。

搜索

可以搜标题、编号或内容，能用拼音，也能用首字母，比如搜「tk」能找到「退款」。几个词可以一起搜，只搜当前目录或者全部都行。

带【变量】的话术

话术里的【变量】会变成高亮的空。点一下直接填，按回车跳到下一个空，全填好就复制。软件开着的时候，每个空会记住最近填过的三个值，下次点一下就能用。

收藏和最近使用

常用的话术可以收藏，收藏的排在最前面。「最近」里是刚用过的。

批量移动和删除

点「选择」，勾上几条，可以一起「移动到」别的目录，或者一起移入回收站。删错了，6 秒内可以撤销，之后也能在回收站里找回来。

导入表格

在「设置 → 数据 → 导入话术表格」里选一个 .xlsx 或 .csv 表格。表格只在本机读取，导入是合并，不会覆盖已有的话术；格式不对或重复的行会告诉你。

账号

登录账号、付款方式、API 密钥、验证码、恢复码这些资料，可以分类存在这里，用的时候点一下复制。

设密码

账号页可以设一个密码，至少 8 个字符。设了以后，账号里的内容会用这个密码单独加密，就算有人拿到电脑里的文件也打不开。

恢复码一定要存好

设密码时会给你一个恢复码。请抄在纸上，或者存进密码管理器。忘了密码，可以「用恢复码找回」，再设一个新密码。

密码和恢复码都丢了，账号里的内容就打不开了，谁都没办法找回。

解锁

打开账号页时输入密码就能看到内容。离开账号页，它会自动重新锁上。

图片

常发的图片，比如尺码表、产品图、收款码，存在这里，点一下就复制，直接粘贴到聊天窗口。

放入图片

可以选文件，也可以把图片拖进来或者直接粘贴。新放入的图片会先压缩再保存，占的地方更小。

目录

图片也能分目录，可以新建、改名、换颜色。删掉一个目录，里面的图片会留在「未分类」里，不会丢。

宫格和列表

可以用「宫格」一眼看很多张，图片完整显示不裁切；也可以换成「列表」。每张图上都有复制按钮。

回收站

删掉的图片先进回收站，在那里可以恢复，或者彻底删除。

托盘小窗

Clipboxx 开着的时候，屏幕右下角的托盘里有它的图标。点一下图标，会弹出一个小窗口，固定在最上面，适合边聊边复制。

  • 复制完收起：在「设置 → 窗口 → 迷你窗口复制后」里选「从托盘呼出时收起」「总是收起」或「不收起」。
  • 点窗口的关闭按钮时：可以选「收到托盘」（继续在后台运行，随时叫出来）、「缩到任务栏」或者「退出」。
  • 开机自动启动：打开以后，登录电脑时 Clipboxx 会自己启动，安静地收在托盘里。

备份与恢复

完整备份

「设置 → 数据 → 完整备份」会把话术、账号、图片和设置打包成一个文件，用你自己设的密码加密。密码至少 8 个字符，Clipboxx 找不回这个密码，请记好。

每天自动备份

默认打开。每天自动存一份完整备份，保留最近 7 份，放在 Clipboxx 自己的数据文件夹里。它没有单独的密码，要把备份带走，请用带密码的「完整备份」。

恢复

「从完整备份恢复」会用文件里的内容替换现在的全部内容，替换前会再问你一次。账号设过密码的话，恢复以后还是用原来的密码或恢复码打开。

只想备份话术，可以用「导出话术备份」；「导入备份」能选合并或者覆盖。

公司共享话术

公司统一维护的话术，可以同步到每个人的 Clipboxx 里。在「设置 → 数据 → 共享话术」里填上公司给的地址，打开软件时会自动同步；没有地址的话，用管理员发来的 .json 文件「从文件同步」。

  • 同步只会新增话术，和更新你没改过的那些。你自己写的和改过的，不会被覆盖或删除。
  • 你改过的话术，公司那边也更新了，会标「公司版有更新」，你可以选「保留我的」或者「用公司版」。
  • 公司删掉的话术只会标「公司已停用」，你可以接着用，也可以自己删。

AI 润色和整理

这是可选功能，不用也完全不影响别的。话术旁边有「AI 润色」和「AI 整理」，改完不满意可以撤销。

  • 在「设置 → AI」里选一个服务（比如 DeepSeek、Kimi、智谱 GLM、硅基流动、OpenAI），或者填自己的接口地址、模型和密钥。
  • 密钥由系统加密，保存在本机，只会发给你填的那个接口。备份里不带密钥，换电脑后要重新填一次。
  • 没填接口时，「AI 整理」按规则整理，「AI 润色」用不了。

设置

  • 主题：跟随系统、浅色、深色。跟随系统会随电脑的深浅色自动切换。
  • 数据位置：在「设置 → 数据」里点「打开文件夹」，能看到 Clipboxx 的数据放在哪。里面有解密用的密钥，请不要把整个文件夹拷给别人。
  • 回收站：可以设过多少天自动清理，也可以一次清空。清空以后就找不回来了。

常见问题

数据存在哪里？

都在你自己的电脑上，加密保存，不会上传。在「设置 → 数据 → 数据位置」能打开它所在的文件夹。

忘了账号密码怎么办？

用设密码时给你的恢复码找回，再设一个新密码。密码和恢复码都丢了，账号里的内容就打不开了，所以恢复码一定要存好。

换电脑怎么搬？

在旧电脑点「设置 → 数据 → 完整备份」，设一个密码，把文件拷到新电脑。新电脑装好以后点「从完整备份恢复」，输入同一个密码。

AI 的密钥不在备份里，到新电脑上要重新填一次。

为什么 Windows 提示未知发布者？

安装包没有做数字签名，所以 Windows 会提醒一下。点「更多信息」，再点「仍要运行」就能装。

和旧版 Clipbox 是什么关系？

Clipboxx 就是原来的 Clipbox，只是改了名字。旧版的数据可以搬过来：先在旧版点「设置 → 数据 → 导出到新版」，再在新版点「设置 → 数据 → 从完整备份恢复」。详细步骤见从旧版搬数据。
