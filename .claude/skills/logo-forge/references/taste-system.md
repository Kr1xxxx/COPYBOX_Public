# Taste System — Dials and Anchors

Read at Step 2, before generating candidates. This is what turns "generate a logo" into a specific, defensible direction instead of an average of every logo the model has ever seen.

## Style dials (pick one position on each, don't leave any unset)

**Proportion system**
- φ (golden ratio) — timeless/classical framing. Use when the brief says "established," "heritage," "premium/luxury."
- 1:1 — stability/reliability framing. Good default; use when the brief doesn't specify.
- 3:2 — editorial/dynamic framing. Use when the brief says "bold," "modern," "energetic."

**Construction language**
- Geometric — hard edges, constructed curves, grid-visible. Reads as precise/technical.
- Organic — softer, hand-drawn-adjacent but still gridded (organic ≠ freehand — see anti-patterns.md #11). Reads as approachable/human.

**Density**
- Minimal — one shape, one idea, maximum negative space.
- Detailed — more internal structure, still resolved to one grid, still passes the 16px legibility test.

**Color count**
- 1 (monochrome mark, color applied only in the wordmark or not at all)
- 2 (default) — one primary, one accent, tested in both orders (primary-on-accent and accent-on-primary)

## Canonical design-language anchors

Pick one as the reference point for a given run — this replaces "what do other logos in this space look like" with an actual visual grammar:

- **Bauhaus** — primary geometric shapes (circle, square, triangle), primary or near-primary colors, function-follows-form. Good for construction/education/craft niches.
- **Swiss International / International Typographic Style** — grid-driven, sans-serif, asymmetric balance, restrained color (often near-monochrome + one accent). Good for anything wanting to read as precise/technical/no-nonsense.
- **Memphis** — playful geometric collage, unexpected color pairing, deliberately "loud" within a controlled palette. Good for consumer/lifestyle/youth-oriented niches — use carefully, easy to overdo.
- **Mid-century modern** — organic-but-controlled curves, warm restrained palettes, confident simple shapes. Good for hospitality/food/craft niches.
- **Constructivism** — diagonal energy, bold geometric intersection, high contrast. Good for anything wanting to read as dynamic/movement-oriented.

If the brief gives no preference, pick the anchor whose framing best matches the niche and state the assumption in the delivered spec sheet — don't silently default to "generic geometric abstraction," which is anti-pattern #5/#12 territory.

## Default banned-motif list (start here, add project-specific bans to BRAND.spec.md)

- Circular gradient blob with radiating internal elements (anti-patterns.md #1)
- Generic single-swoosh path (#2)
- Gradient used to compensate for an unresolved flat shape (#3)
- Shield/badge outline as a generic trust container (#4)
- Checkmark / lightbulb / blue-circle as the entire concept (#5)
- Abstract V-man figure (#6)
- Purple→blue or teal→blue default "tech" gradient (#13)
- Neon-on-dark as a default "AI/modern" palette (#14)

## Concrete-metaphor seed list (use if the brief gives no anchor object)

Pick something literally present in the niche, not a metaphor for the *category* the niche belongs to:
- A specific tool, instrument, or piece of equipment used in the work
- A specific ingredient, material, or raw input
- A specific action or gesture central to the work (not "growth" in the abstract — the actual physical motion)
- A local landmark, geographic feature, or cultural motif specific to where the brand operates, if relevant and not appropriative
