# 产品决定记录

负责人已经定下的事。新的 agent 或开发人员不要推翻；要改，先问负责人，改完在这里追加一行。
格式：日期 — 决定（原因 / 范围）。

## 平台

- 2026-10 — **Windows 优先**。主要用户是 Windows。
- 2026-10-08 — macOS **只出 Apple 芯片（M 系列，arm64）**，不出 Intel 版。
- 2026-10 — Windows 的第二板块叫“备注”；macOS 仍叫“秘密”。
- 2026-10-08 — Windows 的“备注”是**纯文字备注**：内容直接显示，没有隐藏、按住显示、复制引用、“被什么引用”、分段。macOS 的“秘密”保留这些功能。

## 界面（方案 H）

- 左右布局：128px 侧栏 + 搜索优先的内容区；选中的条目在列表里原地展开，不弹窗。
- 完整窗口最小 **680×620**（不能再小），迷你窗口固定 **360×440**、置顶。
- 隐藏滚动条；长内容用渐变阴影提示还能滚动。
- 列表里**不显示**总结/简略词（如“跟进报价”）和复制时间。
- 展开卡片的标题行要紧凑；切换条目有动画，旧卡片要**慢慢收起**，不能瞬间消失，收起时边框不能闪白。
- 编辑、填变量、新建目录都在原位完成，不弹窗。

## 功能

- 2026-10-08 — **不要任何快捷键**：没有快捷键提示（kbd 标记、状态栏提示）、没有 Ctrl/⌘ 组合键、没有 Alt+方向键排序、没有全局唤起键。搜索框里方向键选择、回车复制、Esc 返回属于普通操作，保留但不写提示。窗口从托盘图标呼出。
- 2026-10 — **去掉“复制后自动清除剪贴板”**（两个平台都去掉，不加回）。
- 2026-10 — 设置里**不写命令行和快捷键说明**（Mac 也不加回）。
- 2026-10 — 话术的备注字段叫 **“小提示”**（最多 40 字），避免和 Windows 的“备注”板块重名。
- 2026-10 — 话术内容旁有 **AI 润色 / AI 整理**，可撤销。
- 2026-10-08 — AI 用**用户自己在设置里填的接口**（兼容 OpenAI chat/completions）：地址、模型、API Key、润色提示词、整理提示词；**提示词为空不能保存**；提供常用服务预设和“获取模型”。API Key 用系统加密只存在本机。没填接口时用系统自带本机 AI，再没有时“整理”用规则、“润色”不可用。
- 目录：标准话术目录（询盘接待、产品样品、报价成交、定制生产、客户跟进、物流清关、售后争议）固定，只能改颜色；其他目录可新建、改名、改色、删除，侧栏和设置里都能拖动排序（设置里另有上移/下移）。

## 流程

- 不直接推 `main`；开 PR，**负责人同意后才合并**。
- 汇报用四段：做了什么 / 没做好的地方 / 需要你做的 / 建议下一步。
- 能做的就做完，不把能做的事留成注意事项。
