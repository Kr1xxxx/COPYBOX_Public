# 移除话术优先级设计

## 目标

从 Clipbox 完整移除话术“优先级”概念，避免保留没有实际价值的界面和数据字段。

## 范围

- 编辑弹窗不再显示“高优先级”徽标或优先级选择框。
- `SnippetMeta` 不再包含 `priority` 字段，也不再暴露 `SnippetPriority` 类型。
- 表格中的“优先级”列可以继续存在于原始文件，但导入规范化时忽略该列。
- 删除已无消费者的优先级排序辅助函数。
- 读取旧版加密数据时移除历史 `priority` 字段，其他话术字段与固定编号保持不变。

## 界面

“中文对照与使用规则”折叠栏只保留标题。展开后“产品 / 业务”字段占满整行，后续依次显示中文对照和使用备注，不留下空列或占位。

## 验证

- 单元测试证明新导入话术不生成 `priority`，旧加密数据中的 `priority` 会在规范化时删除。
- 真实弹窗中不存在“优先级”文字、徽标和选择框。
- 完整测试、Lint、生产构建与桌面打包通过。
