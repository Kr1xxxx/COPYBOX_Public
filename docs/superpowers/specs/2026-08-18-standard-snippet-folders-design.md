# Clipbox 标准话术目录设计

**状态：** 已由用户批准并要求在当前任务执行。

## 目标

把话术浏览固定为跨境电商客户流程中的七个标准目录，同时保留 160 条原始话术、固定编号和现有 `clipbox list/get/add/update/move/delete` 命令形态。

## 数据与导航

话术目录固定按以下顺序显示，数量来自当前数据：

1. 询盘接待（22）
2. 产品样品（29）
3. 报价成交（24）
4. 定制生产（21）
5. 客户跟进（22）
6. 物流清关（20）
7. 售后争议（22）

话术导航只显示“全部话术”和上述七项。秘密目录仍保留现有自由新增、手写和拖动排序能力。

## 行为

- 选择话术目录后，搜索只在该目录内进行。
- 搜索覆盖编号、标题、总结、英文话术和中文对照。
- 话术列表依次呈现标题、中文总结、编号和英文内容预览。
- 新增话术默认使用当前目录；未选择目录时默认“询盘接待”。编辑、移动和导入只能使用七个标准目录。
- 旧目录名在导入时映射到对应标准目录；未知目录拒绝导入，不创建近义目录。
- 标题统一为“场景 · 动作”。对现有未规范标题使用“原标题 · 当前总结”，不改写中英文话术。
- 不删除或自动合并疑似重复话术，只在完成报告中列出编号组。

## 数据安全

- 修改本地数据前复制完整加密配置目录作为备份。
- 标题更新使用已有 CLI，编号、内容、目录及总数保持不变。
- CLI 验收使用一个临时话术完成 add/get/update/move/delete 闭环，结束后恢复 160 条和原目录数量。
