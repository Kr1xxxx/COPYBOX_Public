# Clipbox v0.2.22 Windows Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update the Windows snippet-only installer to the exact current v0.2.22 working-tree state while preserving every approved Windows restriction and the existing macOS behavior.

**Architecture:** Capture the committed and uncommitted v0.2.22 worktree as an immutable Git commit without changing that worktree, then merge the snapshot into `codex/windows-snippet-only`. Resolve the integration around the existing edition policy and platform profile: macOS keeps the full v0.2.22 application and automation bridge, while Windows remains snippet-only, import-only, fixed to port 47183, without global automation or a global shortcut.

**Tech Stack:** TypeScript, React 19, Vinext/Vite, Electron 44, Node test runner, electron-builder NSIS.

**Spec:** `docs/superpowers/specs/2026-08-25-clipbox-windows-snippet-only-design.md` and `docs/superpowers/specs/2026-08-17-clipbox-structured-snippet-import-design.md`

## Global Constraints

- Include all committed and uncommitted files currently present in `.worktrees/structured-snippet-import` at version `0.2.22`.
- Windows exposes snippets only; legacy or imported secrets are filtered and erased from the Windows vault.
- Windows can import supported snippet backups and spreadsheets, but cannot export snippets or secrets.
- Windows does not register a global keyboard shortcut; installer desktop and Start menu launch shortcuts remain enabled.
- Windows uses the stable loopback origin `http://127.0.0.1:47183/?clipbox-desktop=win32`.
- Windows ships only an x64 NSIS installer.
- Windows uses `"Microsoft YaHei UI", "Microsoft YaHei", "Segoe UI", sans-serif`; snippet title weights remain primary `600`, detail `500`, and separator `400`.
- macOS presentation, secrets, export, `⌥ Space`, automation, and current port behavior remain enabled.
- Keep Electron `44.0.0`, React `19.2.8`, React Server DOM Webpack `19.2.8`, Vinext `1.0.0-beta.8`, Vite `8.2.2`, and the existing conservative packaging trims.
- Do not modify or clean unrelated untracked files in the primary workspace.
