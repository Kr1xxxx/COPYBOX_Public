# Tips 导入模板要求

在 App 里点「设置 → 数据 → 导入 Tips → 选择文件…」，选文件就能导入，不用改代码。
只支持两种文件：**.md 文档**和 **.xlsx / .csv 表格**。其他格式都不支持。
现在的《每日小贴士》文档（docs/company-tips.md）就是标准格式。

## .md 文档的写法

| 写法 | 作用 |
| --- | --- |
| `**标题**` | 一条 Tips 的开始，标题必须单独一行，最多 40 个字 |
| 普通文字 | 说明，可以写多行 |
| `✅ 正确写法` | 显示成高亮块，一行一个 |
| `❌ 错误写法` | 显示成划掉的错误示例，一行一个 |
| `来源: …` | 显示在这条 Tips 最后 |

- `#` 标题、`>` 开头的说明、`- ` 开头的列表行和 `---` 都会跳过，不会导入。说明文字不要用 `- ` 开头。
- 一条 Tips 的说明最多 1000 个字，每个示例最多 300 个字，最多 12 个示例。

```markdown
## 一, 称呼

**拿不准就叫 lovely**
lovely 是最通用, 最不会出错的称呼.
✅ Hi lovely 👋
❌ Hi dear
来源: 根据 2026 年阿里对话数据
```

## 表格的写法

第一行是列名，每一行是一条 Tips。

| 列名 | 必须有 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 没有标题的行会跳过 |
| 内容 | 是 | 说明文字 |
| 正确写法 | 否 | 一个格子里可以写多行，每行一个高亮块 |
| 错误写法 | 否 | 同上 |
| 来源 | 否 | |

## 重复导入

- 同一个标题算同一条 Tips：再导入时会更新内容，不会重复。
- 标题和软件自带的 Tips 一样，就替换自带的那条。
- 导入不会删除任何 Tips。改了标题会变成一条新的 Tips。
