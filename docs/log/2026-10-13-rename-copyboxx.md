# Copyboxx: new name, Chinese installer without stock pictures, new icon, old launch-at-login entries moved

- Date: 2026-10-13 · Thread/agent: coordinator worker W11 (rename-copyboxx)
- What changed: Every user-visible Clipboxx is now Copyboxx (app, `clipbox` command messages, tray, window title, web preview, website incl. `download/Copyboxx-Setup.exe`, README, `productName`, publisher, release files `Copyboxx-Windows-setup.exe` / `Copyboxx-macOS-arm64.zip`, release title 「Copyboxx 测试版 #N（测试用，不是正式版）」). The NSIS installer is Simplified Chinese only, uses the app icon, a plain brand picture (icon + 复制盒) instead of NSIS's blue computer picture on its first and last page, and 「Copyboxx 复制盒」 instead of "Nullsoft Install System" at the bottom. New icon (box with two overlapping cards) from `src-tauri/icons/icon.svg`, rendered by `scripts/render-icons.mjs`. On Windows the app removes launch-at-login entries left by Clipbox/Clipboxx installs and switches launch at login on for itself when one was on (`src-tauri/src/old_autostart.rs`). D-046.
- User-visible change (plain Chinese, for the preview changelog): 产品名改为 Copyboxx（复制盒）；换了新图标（盒子里两张叠在一起的卡片）；Windows 安装包改成中文，去掉了安装时左边那张默认的电脑图片，换成复制盒的图标；装好新版后，旧版设置的开机启动会自动转到新版。
- Not done / risks: The installer, the registry clean-up and the tray icon were not run on Windows (no Windows here): the NSIS assets were checked with makensis 3.09 on Linux and the Rust code with unit tests and a Windows-target clippy run of the new module against stub tauri crates (the full crate cannot be compiled for Windows here). While the old Clipboxx is still running (for example in the tray after a login), opening Copyboxx only brings up the old window (shared single-instance lock) and the launch-at-login move waits until the old one has been quit once; the installer does not close it because it only looks for its own install folder. The website still serves the old installer until the coordinator builds a new test release and deploys. The in-app padlock mark (loading screen, 账号 lock screen) was left as it is. On the Mac the tray uses the app icon as a template image, so it shows as a plain rounded square (as before, now without the outer square).
- Next step: Publish a `tauri-test-N` build, install it on Windows over a Clipboxx install with launch at login on, restart, and check that Copyboxx starts in the tray and 设置 shows 开机启动 on; then deploy the website.
