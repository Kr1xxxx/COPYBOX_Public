# Pin the full window on top

- Date: 2026-10-13 · Thread/agent: W12 (worker)
- What changed: The full window's toolbar has a pin button (固定在最上层 / 取消固定) left of 迷你模式. It is remembered in the new localStorage key clipbox.pin-on-top and sent to the shell on start through the new bridge method setPinned and Tauri command set_pinned; window_mode.rs keeps the flag, so going back from the mini window to the full window keeps the full window on top when pinned (the mini window is always on top as before). The button only shows when the desktop shell or the web preview's stand-in offers setPinned; the preview's setPinned does nothing.
- User-visible change (plain Chinese, for the preview changelog): 完整窗口顶部新增「固定在最上层」按钮：打开后窗口一直在其他窗口上面，再点一次取消；重启后仍记得。
- Not done / risks: Not tried in the real desktop app on Windows or macOS (only the browser with a fake shell, plus the Rust unit test for the on-top rule).
- Next step: Walk through it in the Windows build (pin, switch to mini and back, restart) and mark it in docs/features.json.
