# Preview 2.00: app version without a leading zero

- Date: 2026-10-15 · Thread/agent: 功能 · 安全分页與自動上鎖 (preview publisher for v2.00)
- What changed: The preview goes from 1.99 to 2.00. An app version may not have a leading zero ("2.00.0" is not a
  valid version for Cargo or the updater), so `appVersionFrom` now gives "2.00" → "2.0.0", "2.05" → "2.5.0", "2.10" →
  "2.10.0" (still in order), and the new `previewFromApp` turns an installer's app version back into its preview
  number for the website build. 1.x numbers map exactly as before.
- User-visible change (plain Chinese, for the preview changelog): 无（安装包里显示的版本号从 2.0.0 开始）
- Not done / risks: The private repo picks this up on its next sync from public main; until then a private build of
  2.00 would fail on the version number.
