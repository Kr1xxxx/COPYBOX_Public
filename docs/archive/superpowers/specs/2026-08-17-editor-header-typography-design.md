# 编辑弹窗顶部字体层级优化

## 问题

编辑弹窗顶部的 `CB-0003` 使用 `font: ... var(--font-geist-mono)`，但项目没有定义 `--font-geist-mono`。浏览器因此丢弃整条 `font` 声明，编号继承父级字号，造成“话术 / 编号 / 编辑内容 / 说明”比例混乱。

## 设计

- 在根字体令牌中定义明确的系统无衬线与等宽字体栈，消除缺失变量导致的继承异常。
- 顶部信息按四级组织：类型标签 9px、固定编号 10px、主标题 20px、辅助说明 10px。
- 类型标签与编号保持在同一行，编号使用低对比度等宽字，不再与主标题竞争。
- 主标题与元信息行之间保持 7px 间距，说明与标题之间保持 4px 间距。
- 头部总高度不明显增加，关闭按钮、正文表单、底部操作区不改结构。

## 验证

- 在真实 Electron 弹窗中读取四类文字的计算字号与字体族。
- 分别检查 680×620 和 500×520 视口下的截图，确认无文字重叠、截断和横向溢出。
- 完整测试、Lint、生产构建和桌面打包必须通过。
