# Clipbox 结构化话术整理与导入设计规格

## 目标

将《跨境电商即时消息话术库_160条_含使用规则.xlsx》整理为 Clipbox 可长期维护的结构化话术，并导入当前本地加密保险库。Clipbox 继续是一款紧凑的 macOS 复制工具，不扩展为客户、订单或销售流程 CRM。

成功标准：

- 原始工作簿保持不变，并生成一份规范化导入副本。
- 160 条话术全部可被解析、预览并导入；重复导入不会重复创建相同内容。
- 13 个沟通阶段成为话术目录，产品/业务成为结构化筛选信息而不是第二层目录。
- 英文为默认复制内容，中文可查看和单独复制。
- 真正出现在正文中的方括号变量在复制前填写；仅表示发送前确认事项的字段作为检查项展示。
- 金额、库存和时效类话术在复制前显示核实提醒。
- 旧保险库、旧条目和旧 JSON 备份继续无损工作。

## 方案选择

### 采用：在现有条目上增加可选话术元数据

`SecretItem` 仍是唯一条目模型，仅为 `kind: "snippet"` 增加可选 `snippetMeta`。这样可以复用现有加密、目录、搜索、列表、置顶和导入合并逻辑，同时避免把跨境话术字段挤进 `note`。

### 未采用：把结构化信息拼入备注

改动最少，但备注目前会在编辑保存时被清空，字段无法可靠搜索、校验或单独复制，也无法区分正文变量与发送前检查项。

### 未采用：创建独立话术数据库与工作台

能够支持更复杂的标签和批量管理，但会引入第二套导航、编辑和持久化模型，超出当前 160 条个人话术库的必要复杂度。

## 设计方向

Reading this as: 在现有紧凑型 macOS 工具中加入专业话术能力，界面应安静、密集、可键盘操作，并保持复制动作直接。

- `DESIGN_VARIANCE: 4`：保留当前主窗口、侧栏、列表和紫色强调色。
- `MOTION_INTENSITY: 2`：只为导入预览、变量填写和复制反馈提供短状态过渡。
- `VISUAL_DENSITY: 8`：筛选与元数据按需展开，不把产品标签铺满主窗口。

Taste Skill 与 Open Design 用于信息层级、状态完整性、键盘可达性和高频操作效率，不改变现有产品视觉身份。

## 数据整理规则

### 保留原始信息

规范化文件保留原工作表中的原始标题、阶段、场景、动作、产品/业务、英文、中文、可替换变量、使用备注和优先级。原始行号作为 `sourceRow` 保存，方便回查。

### 派生字段

- `folder`：沟通阶段，共 13 个目录。
- `label`：具体场景；若同一场景在多行出现，使用“具体场景 · 核心动作”避免列表歧义。
- `summary`：核心动作，不再强制截断为 10 字；普通手动话术仍沿用现有短总结规则。
- `productGroups`：从产品/业务映射到固定分类：睫毛、镊子、假发/发束、洗发水、包装/Logo、物流/清关、平台、通用。
- `placeholders`：仅提取英文或中文正文中实际出现的 `[变量]`。
- `requiredInputs`：原“可替换变量”中声明但没有以方括号出现在正文里的信息。
- `requiresVerification`：使用备注涉及金额、库存、物流时效、日期或地址核实时为 `true`。
- 搜索文本在运行时由标题、阶段、场景、动作、产品、英文和中文组合，不持久化原表的派生“搜索关键词”。

### 相似话术

两组高相似话术保留为独立条目，因为沟通阶段和使用语境不同；导入预览中标记为“相似内容”，不自动删除。完全相同的类型、标题和英文正文才视为重复。

## 数据模型

```ts
type SnippetPriority = "高" | "中";

type SnippetMeta = {
  stage: string;
  scene: string;
  action: string;
  productGroups: string[];
  rawProduct: string;
  chineseText: string;
  placeholders: string[];
  requiredInputs: string[];
  usageNote: string;
  priority: SnippetPriority;
  requiresVerification: boolean;
  sourceRow?: number;
};

type SecretItem = {
  // 现有字段保持不变
  snippetMeta?: SnippetMeta;
};
```

所有新增字段都可选。解密旧数据时缺少 `snippetMeta` 的话术按普通话术显示和复制。

## Excel 导入流程

### 文件选择与解析

- 备份弹窗增加“导入话术表格”，接受 `.xlsx` 和 `.csv`。
- 解析在本机完成，不上传文件。
- `.xlsx` 优先读取名为“话术库”的工作表；不存在时读取第一个包含必需列的工作表。
- 必需列为：标题、沟通阶段、具体场景、核心动作、英文即时消息、中文对照。
- 可选列缺失时使用空值或默认中优先级，不阻断导入。

### 预览

解析后显示总行数、可导入数、重复数、错误数、将创建的目录，以及前几条话术预览。存在错误的行给出行号和原因，不写入保险库。

用户确认后采用合并导入：

- 新话术写入 `kind: "snippet"`。
- 目录与现有话术目录合并。
- 完全重复项跳过。
- 导入完成后切换到话术板块并显示结果反馈。

本轮不提供 Excel 覆盖整个保险库，避免表格导入误删秘密或手工话术。

## 主窗口与搜索

- 默认列表结构保持不变：主行显示场景，副行显示核心动作。
- 搜索扩展到 `snippetMeta` 的阶段、场景、动作、产品、中文和英文。
- 高优先级参与搜索结果中的轻量排序，但不自动置顶 105 条内容。
- 产品筛选放在搜索栏旁的紧凑弹出菜单中；默认“全部产品”。
- 没有结构化元数据的旧话术不受筛选影响，只在“全部产品”中显示。

## 查看、编辑与复制

### 查看和编辑

- 话术编辑器继续以英文内容作为主文本域。
- 结构化话术增加可折叠的中文对照、产品分类、使用备注和优先级区域。
- 场景与动作可编辑，保存时同步更新列表标题和摘要。
- 普通手动话术维持当前简洁编辑器，不强迫填写结构化字段。

### 复制

- 行点击和现有复制按钮默认复制英文。
- 中文对照提供独立复制按钮。
- 正文没有占位符时保持一击复制。
- 存在占位符时打开轻量填写面板，每个变量一个输入框；实时生成预览，未填写时不执行最终复制。
- `requiredInputs` 显示为发送前检查清单，不自动替换正文。
- `requiresVerification` 为真时显示“发送前核实金额、库存或时效”，用户确认后才复制。
- 完成复制后仍沿用现有成功反馈并更新最近使用时间。

## 生成的导入文件

在原文件同目录生成新文件 `跨境电商即时消息话术库_Clipbox导入版.xlsx`，不覆盖原件。导入版包含：

- `Clipbox导入`：标准化后的可导入字段。
- `需人工复核`：高相似话术、变量声明不一致和缺失/异常行。
- `字段说明`：每列用途、产品分类映射和导入规则。

文件需要重新读取并渲染检查，确保 160 条数据、标题行、筛选范围、冻结表头和中文显示完整。

## 错误与边界状态

- 文件格式不支持、工作表缺失或列名不匹配时，显示具体错误，不修改保险库。
- 单行错误不阻断其他有效行进入预览，但用户能看到被跳过的数量和行号。
- 空英文正文不得导入。
- 占位符按原文方括号内容去重；英文和中文使用同名变量时只显示一个输入框。
- 关闭预览或变量面板时不写入任何内容。
- 导入持久化失败时保留当前保险库状态，并显示错误。
- 导入文件和保险库均不得包含账号密码、令牌或设备密钥。

## 测试与验证

### 测试先行

- 工作表列识别、160 行解析、阶段目录和产品分类映射。
- 占位符提取、`requiredInputs` 拆分和核实提醒判断。
- 重复项检测、错误行报告和目录合并。
- 结构化字段加入搜索，普通旧话术仍可搜索。
- 占位符完整填写后才能生成最终复制文本。
- 旧保险库、旧备份和普通话术保持兼容。

### 工程验证

- 运行聚焦测试，先确认新增测试因缺少功能而失败，再实现至通过。
- 运行 `npm test`、`npm run lint` 和 `npm run build`。
- 对导入版工作簿执行重新读取、字段计数和渲染检查。

### 行为与视觉检查

- 在 `680 × 620` 和 `500 × 520` 检查导入预览、结构化编辑器和变量填写面板。
- 检查长英文、长中文、多个变量、零变量、警告和错误状态。
- 检查键盘焦点、Esc 关闭、按钮禁用状态和减少动态效果。
- 在 Electron 中完成一次实际表格导入，确认 160 条话术和 13 个目录进入本地加密保险库。

## 不在本轮范围

- 客户资料、订单、销售漏斗、自动发送和聊天软件连接。
- 云端同步、多人协作或远端数据库。
- 自动合并语义相似但上下文不同的话术。
- 批量 AI 改写、翻译或生成新话术。
- 改造秘密板块或重新设计主窗口视觉主题。
