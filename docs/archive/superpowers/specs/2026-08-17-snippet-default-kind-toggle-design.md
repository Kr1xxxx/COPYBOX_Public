# Clipbox 默认话术与单栏切换设计

## 目标

Clipbox 启动后默认进入“话术”。侧栏顶部不再同时展示“秘密”和“话术”，而是只展示当前内容类型：默认显示“话术”，点击后切换为“秘密”，再次点击“秘密”返回“话术”。

## 交互

- 初始内容类型固定为 `snippet`。
- 顶部单栏显示当前类型名称和当前类型数量。
- 点击单栏切换到另一类型，同时将目录恢复为“全部”、产品筛选恢复为“全部产品”、搜索词清空、选中项回到第一项。
- 单栏通过 `aria-label` 明确告知点击后的目标类型。
- 不增加额外开关、弹窗或动画；沿用现有按钮按压反馈。

## 视觉

原来容纳两个入口的 62px 双行区域收紧为 34px 单行区域，保持现有圆角、背景、字重与数量徽标，减少侧栏顶部占用。

## 验证

- 单元测试覆盖默认类型及双向切换。
- 生产构建、Lint、桌面打包通过。
- 安装后确认首次打开为话术，点击可切到秘密并可返回，500px 宽窗口无溢出。
