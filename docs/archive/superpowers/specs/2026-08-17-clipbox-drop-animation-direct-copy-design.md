# Clipbox 拖动归位动画与直接复制设计

## 目标

改善卡片和目录拖动完成后的突兀跳转，同时取消结构化话术的强制复制前确认。默认复制路径必须保持最快：点击、双击、搜索回车和中文复制都立即写入剪贴板。变量填写与核对继续保留，但成为完全可选的辅助路径。

## 交互设计

### 拖动归位

- 指针拖动松手并发生有效换位后，移动项与被挤开的可见项平滑过渡到新位置。
- 动画服务于空间连续性，不增加弹跳、缩放或装饰性透明度变化。
- 时长为 220ms，曲线使用 `cubic-bezier(0.77, 0, 0.175, 1)`。
- 只在指针拖动后播放。`Option + ArrowUp/ArrowDown` 键盘排序保持即时，避免高频键盘操作产生延迟感。
- 系统启用“减少动态效果”时跳过位移动画。
- 加密保存失败并回滚顺序时，同样用一次短归位动画解释恢复过程。

### 复制路径

- 现有英文复制按钮始终直接复制英文原文。
- 现有中文按钮始终直接复制中文原文。
- 双击卡片与搜索结果回车直接复制英文原文。
- 即使原文含 `[Customer Name]`、`[Price]` 等占位符，仍按原样立即复制。
- 含占位符、发送前核对项或核实提示的话术显示一个小型“填”按钮。
- “填”按钮打开现有准备复制窗口，用户可填写变量、勾选核对项后复制。这条路径是可选增强，不影响任何直接复制入口。
- 不含准备项的话术不显示“填”按钮，避免无功能的视觉噪声。

## 技术设计

### FLIP 动画

新增一个小型、无 React 状态的布局动画工具：

1. 指针拖动的 `onDrop` 回调在更新顺序前读取当前可见排序节点的 `DOMRect`。
2. 现有 `persist` 继续同步提交乐观 UI 状态。
3. `useLayoutEffect` 在 React 完成新顺序布局后读取相同节点的新位置。
4. 对位置改变的节点调用原生 Web Animations API，从旧位置与新位置的差值过渡到 `translate3d(0, 0, 0)`。

动画只修改合成层友好的 `transform`，不安装动画库，不引入常驻定时器，不在首次加载时执行。动画对象允许新的拖动直接覆盖旧动画，避免快速连续拖动时堆积。

卡片与目录共用同一套位置快照和播放规则，通过 `data-sort-scope` 区分。键盘排序不创建快照，因此不会播放动画。

### 复制职责

现有 `copy(item, language)` 简化为解析语言对应原文并立即调用 `finishCopy`。新增纯函数判断某条话术是否存在可选准备内容，供列表决定是否渲染“填”按钮。

准备窗口及其变量替换、核对逻辑保持不变，但只由“填”按钮显式打开。这样直接复制与准备复制是两条清晰独立的入口，不需要兼容层或隐藏快捷键。

## 错误与边界

- 没有中文原文时不显示中文复制按钮，现有行为不变。
- 没有可选准备内容时不显示“填”按钮。
- 拖动未跨过阈值、目标相同、跨越置顶边界或落在无效区域时不播放归位动画。
- 加密保存失败时恢复原顺序并显示现有错误提示。
- 500px 最小窗口宽度下新增按钮不得引起横向滚动或遮挡主要标题。

## 验证

- 纯函数测试：含任一种准备元数据时显示可选入口；无元数据时不显示。
- 纯函数测试：FLIP 位移计算返回手工推导的 `translate3d` 差值，未移动项不生成动画。
- 回归测试：现有变量替换和准备窗口核对规则继续通过。
- 真实安装版测试：直接点击带核对项的话术会立即复制且不弹窗；“填”按钮仍能打开准备窗口。
- 真实安装版测试：卡片和目录拖动后存在 220ms 的 transform 动画，键盘排序没有动画。
- 视觉检查：680px 常规窗口和 500px 最小宽度均无溢出，动画结束后没有残留 transform。
